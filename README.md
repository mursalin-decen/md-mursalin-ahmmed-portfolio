# MR. STRANGER — Personal Portfolio

A responsive, animated single-page portfolio for Md. Mursalin Ahmmed Zamzam.

## Run locally

No build step is required. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to Vercel

1. Upload this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**. Build command: leave empty. Output directory: `.` (or leave default if Vercel detects the static site).
4. Deploy.

You can also deploy the folder with Vercel CLI using `vercel` from this directory.
